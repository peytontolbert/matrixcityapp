These small source scripts prepare graphics for the community browser adaptations. They read your installed game locally. They do not upload files or include retail artwork.

Duck Game

Select the installed Duck Game folder directly on its game page. The supported uncompressed Windows XNB textures and deathmatch maps are read by the browser.

Broforce & Enter the Gungeon

Install Python 3.11 or newer. Download both files into a new folder:

import-game.py · requirements.txt

Create a virtual environment, activate it, and install the pinned converter dependencies:

python -m venv .venv
# Linux/macOS:
source .venv/bin/activate
# Windows PowerShell instead:
# .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python import-game.py broforce "/path/to/Broforce" "./broforce-assets"
python import-game.py gungeon "/path/to/Enter the Gungeon" "./gungeon-assets"

Choose a new, separate output folder. Select that folder on the game page. The supported versions use Broforce’s sharedtextures.assetbundle and Gungeon’s shared_auto_001 bundle. Other game builds may require an updated importer.

Nuclear Throne

Install the official UndertaleModTool CLI for your operating system. Save both scripts together:

nuclear-import.py · nuclear-assets.csx

python nuclear-import.py "/path/to/Nuclear Throne" "./nuclear-assets" --cli "/path/to/UndertaleModCli"

On Windows, the executable is UndertaleModCli.exe. Select the resulting nuclear-assets folder on the game page. This exports selected sprites and embedded sounds; it does not export game code.

Keep the generated asset folders private. Each friend prepares their own copy. These adaptations contain selected gameplay features, not the complete original engines.
